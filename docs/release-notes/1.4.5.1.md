## Changes

- **Today, Minimal:** the cover card no longer turns when you grab it. Instead, drag the progress line under it to scrub (or click it to jump), as you would in a music app today.

## Fixes

- **Looks that follow the genre** no longer flip to your chosen style and back with every song while the new song's genre is looked up. If the style changes in the middle of a disc change, it waits until the new disc has slid in.
- **Cover colours:** the gear no longer flashes uncoloured between songs, and the pocket player's screen takes the colours too.
- **Import…** never overwrites a skin: one with the same id as yours (or a built-in) gets a new id. A file that doesn't load is reported, not "added".
- **Customise:** a name or genre you type is applied as you type (and when the window closes), not only when you press Return. The previews no longer draw twice after a reload, and an edited skin's preview shows the edit.
- **Today, Minimal with needle meters:** the waveform no longer runs into the needles on small screens.

## Install
Open the DMG, drag Himawari to Applications and open it from there (macOS 14.4 or newer, Apple silicon and Intel). The first time, right-click ▸ Open, since it isn't notarized.
