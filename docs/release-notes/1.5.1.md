## New: updates from the menu

- Himawari now looks for a new version when it starts and once a day. When there is one, it says so (once) and the menu's top item reads **⬆︎ Update to Beta …**: one click downloads it, puts it in place of the old one and reopens. **Check for Updates…** looks now; **Check for Updates Automatically** turns the daily look off. From this version on, updating is one click.

## Fixes

- **The real cover, not the title label:** the cover sometimes turned into the plain title label ("text on the cover") even though the song had one, most often after a style change or on the next song of the same album. Several causes, all fixed:
  - macOS sends a song's cover once per album artwork, so the next song on the same album arrived with none, and Himawari put up the label. It now keeps the last cover the system sent for that album.
  - Music sometimes reads "stopped" for a moment. The same song coming back within a few seconds now keeps its cover, instead of being treated as a new song with no cover yet.
  - The plain label never replaces a real cover the song is already showing.
  - Two quick skips could swap their covers (one temporary file was shared). Each song now has its own.
- **Looks that follow the genre** no longer flip to your chosen style and back when Music reads "stopped" for a moment.
- **A cover that arrives early** goes on the media straight away, while the animated cover is still being looked for, instead of the last song's cover showing under the new title.
- **A sharper cover arriving during a CD change** waits for the change to finish, instead of cancelling the slide.

## Install
Open the DMG, drag Himawari to Applications and open it from there (macOS 14.4 or newer, Apple silicon and Intel). The first time, right-click ▸ Open, since it isn't notarized.
