## Fixes

- **Meters on battery:** the VU needles and the spectrum now follow the music on battery and in Low Power Mode too, at a lower frame rate to save power. Before, they rested while the song played. Only the gear's own made-up animation rests in Battery Saver now.
- **Unmuting under the CD or YouTube:** the video's sound comes back once they're gone, instead of staying silent.
- **Moving lock screen:** if Himawari can't back up Apple's Aerial video first, it no longer swaps it, so the original can't be lost.
- **Disc changer:** no longer stays on "Adding…" when a Spotify link can't be read, and a playlist that had no cover when first seen gets one later.
- **Equalizer:** restoring a preset whose name has a backslash works.
- **Stability:** fixes a possible crash in the CD scene, and reads the system-audio permission correctly.

## Install
Open the DMG, drag Himawari to Applications and open it from there (macOS 14.4 or newer, Apple silicon and Intel). The first time, right-click ▸ Open, since it isn't notarized.
